# Origins Rebirth Wiki

A knowledge base established to document the evolving lore, origin abilities, brewery guides, general tips and tricks.

### If you are viewing this on the wiki site:

Use the navigation menu on the left or the search bar to find the information you need for. If you cannot find what you're looking for, you can add it yourself via the "How to edit the wiki" below or reach out to us on our Discord!

### If you are viewing this on GitHub:

This is the repository for all wiki markdown files. You are welcome to submit a pull request to add, edit or fix content. If you are interested in contributing, please see the "How to edit the wiki" below.

### How to edit the wiki

- Visit [https://wiki-editor.originsrebirth.com/](https://wiki-editor.originsrebirth.com/) to access the web-based editor, sign in with GitHub and begin making your contributions.
- Alternatively, click the "Edit this page" link located in the bottom left corner of any wiki page to access the markdown editor directly.

No special skills or markdown knowledge are required, your help is much appreciated!
